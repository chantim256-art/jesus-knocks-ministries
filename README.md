# JESUS KNOCKS MINISTRIES – Chirala

Static responsive ministry website for GitHub Pages.

## Main files
- `index.html` – all page content and links
- `style.css` – layout, colours and responsive design
- `script.js` – mobile menu, Prayer Request → WhatsApp, gallery lightbox
- `assets/` – ministry and gallery images

## Publishing
Upload the contents of this folder to the root of a GitHub repository and enable GitHub Pages from `main` / root.
